# MermaYT

A Windows GUI wrapper for the [yt-dlp](https://github.com/yt-dlp/yt-dlp) command-line tool.

## About

MermaYT provides a simple graphical interface for downloading audio and video from YouTube via yt-dlp.

## Requirements

- Windows 10 or later

## Tech Stack

- **UI:** WinUI 3
- **Framework:** .NET 8
